Web security edition

Welcome, operative.

A 90-minute deep dive into web security: see why you can never trust the browser, then try the classic injection and access-control flaws against pretend websites, and learn exactly how each one is fixed.

  • Each challenge hides a flag in the format CTF{something_like_this}. Find it, submit it, bank the points.
  • Hints are available but cost points (10% for the first, 30% for the second).
  • You have one clock for everything (90 minutes). Skip hard ones and come back – harder challenges are worth more.
  • Every website here is simulated inside the page. Your browser's developer tools (F12) are your best friend, and perfectly legal on pages you are allowed to look at.
  • The Toolkit tab can decode and encode Base64, which several challenges need.
  • Work in teams of 2–4. Talk to each other. That's how real security teams work.
⚖️ Rules of engagement: Everything here is fictional or simulated. In the real world, only test systems you own or have written permission to test. Unauthorised access is a crime (in the UK, the Computer Misuse Act 1990). Skills for defence, not harm.

Progress saves in this browser, so refreshing won't lose your score. Use one device per team.

🧰 Toolkit

Handy decoders, ciphers and hash tools, running entirely in your browser. Real CTF players use sites like CyberChef too – feel free.

Encode / decode

Ciphers

Caesar, Vigenère and Rail fence read the Input box. XOR expects the input as hex (e.g. 1f 2a 3b or 1f2a3b).

Hash cracker

Paste a wordlist (one word per line) in the Input box above, enter a target hash, pick the algorithm (and a salt if you have one), and see if any word matches. Exactly how attackers use leaked password lists.

Number theory helper

For RSA and Diffie–Hellman style maths. Uses big integers, so large numbers are fine.

📋 Briefing

Suggested pacing for your 90 minutes:

0–10 minWarm-up: view source, then hunt for a forgotten developer comment. 10–40 minThe browser is not your friend: tamper with a hidden field and a cookie. Open DevTools. 40–75 minInjection and access control: SQL injection, XSS and changing an ID in the address. 75–90 minWeb basics and defence: headers, cookie flags, status codes, URLs, and matching every flaw to its fix.

Flag tips

  • Flags look like CTF{...}. Not case-sensitive, but spelling and underscores matter.
  • DevTools: right-click a page element and choose Inspect to edit what the browser holds.
  • Words in flags are lowercase. Numbers are written as digits.
  • Stuck? Try the simplest thing first. Most challenges are puzzles, not brute force.
